# MCP 接入

项目提供两个独立的 Streamable HTTP MCP 入口：

- `/mcp/docs`：匿名只读，只读取当前已发布内容。
- `/mcp/admin`：管理员能力，需要 `Authorization: Bearer <DOCS_MCP_TOKEN>`，可读取草稿并执行受保护的管理操作。

管理令牌由部署者生成，长度至少 32 个字符。不要把它放进浏览器公开配置、截图、提交记录或日志。公开客户端可以直接使用 `/mcp/docs`；管理客户端应使用独立配置。

两套 MCP 使用不同的服务实例和授权边界，即使请求来自同一页面，也不会因为公开浏览权限而获得管理能力。工具列表和参数 schema 由服务端返回，客户端先执行 `tools/list`，再按工具名称调用 `tools/call`。
